# 跌倒預防運動訓練（Exercise for Falls Prevention）

## 適用對象
- 所有社區長者，不論跌倒風險或年齡（GRADE 1A）；中風險者依個別評估提供運動（GRADE E）；高風險者納入多領域介入（[[2022-Montero-Odasso-世界跌倒預防與管理指引]]）
- 特殊族群：
  - 長照機構住民：有督導的個別化運動（1B）
  - 帕金森氏症（1A）
  - 髖部骨折後（1B）
  - 輕度認知障礙或輕中度失智（1B）
  - 中風後（2C）
  - 依據：[[2022-Montero-Odasso-世界跌倒預防與管理指引]]
- 前測評估：跌倒風險分層，見 [[跌倒]]

## 動作範例
| 動作 | 重點提示 |

| 坐站、深蹲 | 可加重量提高難度 |
| 站姿縮小支撐面：雙腳併攏 → 半直線站 → 直線站（腳跟對腳尖）→ 單腳站 | 先扶椅背，再進階到不扶 |
| 多方向跨步、跨越障礙 | 改變速度和方向 |
| 太極 | GRADE 1B |
| 練習從地上起身 | 預防長躺（Long-lie） |

## 禁忌症與安全注意事項
- 由受過訓練的專業人員帶領，依功能狀態和共病調整（[[2022-Montero-Odasso-世界跌倒預防與管理指引]]）。
- 衰弱或高風險者需要更多督導、更小的團體；認知障礙較重者需要小團體或一對一督導（[[2022-Montero-Odasso-世界跌倒預防與管理指引]]）。
- 平衡訓練本身有跌倒風險：要在安全環境中練，旁邊有穩固支撐物或保護者（[[2025-Izquierdo-ICFSR高齡運動全球共識]]）。
- **不要只開「走路」**：只增加一般身體活動不太可能預防跌倒；方案加入走路會降低效果；骨質疏鬆女性單獨走路反而增加骨折風險（[[2022-Montero-Odasso-世界跌倒預防與管理指引]]、[[2025-Izquierdo-ICFSR高齡運動全球共識]]）。
- 立即停止運動的警訊：胸痛、嚴重喘、頭暈、心悸、關節劇痛。

## 預期效果與證據強度
- 多元運動、平衡加功能性運動，或太極，可減少 20–40% 跌倒（[[2025-Izquierdo-ICFSR高齡運動全球共識]]）。
- 以阻力為主（沒有平衡）、舞蹈、步態訓練等方案效果不確定（[[2025-Izquierdo-ICFSR高齡運動全球共識]]）。
- **停止運動後效益就會消失**，必須持續下去（[[2022-Montero-Odasso-世界跌倒預防與管理指引]]）。

## 長者白話版
> 預防跌倒，最有效的是**練平衡和腿力**：
>
> - 一週至少 3 次，至少練 3 個月，而且要一直練下去；一停下來，效果就會消失。
> - 好的動作：從椅子站起來、扶著椅背單腳站、兩腳前後一直線站、往前後左右跨步、跨過小東西、打太極。
> - 先扶著做，穩了再慢慢放手。
> - 只靠散步不夠，一定要加上平衡練習。
> - 也要練習「跌倒後怎麼從地上爬起來」。
>
> 開始新運動前，請先問問醫師或物理治療師。練平衡時，旁邊一定要有穩固的東西可以扶，地上不要有地毯或雜物。
